# Super Metroid: approved coverage study checkpoint

The owner passed manual gameplay review and authorized this local commit on
2026-09-28. Merge/release is not part of this checkpoint.

4,736 to 14,621 audited entry variants; 570 to zero decode conflicts. Matched ROM instruction addresses: 56,610 to 103,624. Attract interprets 55.62% fewer instructions with identical recorded evidence. Basic gameplay retains a sound-handshake timing mismatch (beads-8wg.2.88). The Ceres Ridley return bug is fixed upstream and owner retest passed.

The runtime and generator used are snesrecomp `69d0aae` on
`feat/coverage-feedback`. Reproduction instructions and full evidence are in
that commit's `docs/DISASSEMBLY_AUTHORITY.md` and
`docs/validation/disassembly-2026-09-28.md` / `.json`.

The tested expanded sources are local, ignored artifacts under the engine
worktree's `build/authority-study/sm/continuation-expanded-gen`. This commit
preserves the title-side changes used for validation; it does not change the
normal regeneration inputs or dependency pins to install the expanded candidate.
Permanent integration must reproduce the authority overlay and full generation
using the documented pinned reference and an owned ROM. Never commit ROMs or
generated authority instruction bytes.

Entry variants include CPU M/X modes and mirrors, not unique functions. Finite
state/video comparisons and owner gameplay review do not prove whole-game or
audio waveform equivalence.
